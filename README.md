# 47都道府県・毎日10問クイズ

中学入試向けの地理学習アプリ（開発・公開準備中）。

- 生徒：IDのみでログインし、毎日10問。地図番号・地方区分・都道府県名がすべて正解ならクリア
- 先生：別ID＋パスワードで管理画面にログインし、学習履歴を確認
- 教科書・暗記集を調べながら回答可能

**まだ公開・運用開始していません。**

## 安全性と無料運用について

生徒の本名など個人情報を登録しないでください。IDだけのログインでは他人のIDによるなりすましを防げません。管理者パスワードやDB接続情報をGitHubに置かないでください。

Renderの永続ディスクは無料では利用できません。SQLiteをRenderの一時ストレージに置くと学習記録が消えるため、無料枠の外部データベースへの移行が必要です。
